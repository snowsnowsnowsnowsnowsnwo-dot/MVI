# 천만 영화 분석기

## 프로젝트 소개

위키백과의 「대한민국의 영화 흥행 기록」에서 한국 작품 흥행 순위 표를 수집하고, Python과 Streamlit을 활용하여 천만 영화의 흥행 정보를 분석하고 시각화하는 웹 기반 데이터 수집 및 활용 실습 프로젝트이다.

## 파일 구성

| 파일명 | 설명 |
| --- | --- |
| `app_8_2_movie.py` | 천만 영화 데이터 수집, 정제 및 기본 시각화 |
| `app_8_2_movie_plus.py` | 기본 기능에 개봉 월별 분석 및 감독별 분석을 추가한 확장 버전 |
| `requirements.txt` | 실행에 필요한 라이브러리 목록 |
| `README.md` | 프로젝트 소개 및 실행 방법 |

## 주요 기능

### 기본 기능

- 위키백과 영화 흥행 순위 표 수집 및 데이터 정제
- 천만 영화 편수, 역대 1위 영화 및 관객수 표시
- 가장 최근 천만 영화의 제목과 개봉일 표시
- 영화 흥행 순위 데이터 표 출력
- 관객수 상위 10편 막대 차트 시각화
- 개봉 연도별 천만 영화 편수 시각화

### 추가 기능

- 개봉 월별 천만 영화 편수 시각화
- 여름·겨울방학 시즌(7, 8, 12, 1, 2월) 개봉 영화 편수 및 전체 편수 비교
- 천만 영화를 2편 이상 만든 감독의 이름, 편수 및 작품 목록 출력

## 사용 기술

- Python
- Streamlit: 웹 애플리케이션 구현 및 데이터 시각화
- Requests: 웹페이지 HTML 수집
- BeautifulSoup4: HTML 파싱 및 표 추출
- Pandas: 데이터 정제 및 분석

## 실행 방법

1. 프로젝트 폴더에서 터미널을 실행한다.
2. 필요한 라이브러리를 설치한다.

   ```bash
   python -m pip install -r requirements.txt
   ```

3. 기본 버전 또는 확장 버전을 실행한다.

   **기본 버전**

   ```bash
   python -m streamlit run app_8_2_movie.py
   ```

   **확장 버전**

   ```bash
   python -m streamlit run app_8_2_movie_plus.py
   ```

4. 브라우저에서 `흥행 순위 가져오기` 버튼을 클릭하여 분석 결과를 확인한다.
